# Omnifood Project – Healthy Food Delivery Website

Dự án **Omnifood** là một website landing page được xây dựng bằng **HTML5 + CSS3**, hướng đến việc luyện tập thiết kế web hiện đại, bố cục responsive và giao diện bắt mắt.

## Kiến thức HTML đã áp dụng

- **Cấu trúc chuẩn HTML5**: `<!DOCTYPE html>`, `<head>`, `<meta>`, `<link>`, v.v.
- **Semantic Tags**: `<header>`, `<nav>`, `<section>`, `<main>`, `<article>`, `<footer>`.
- **Thẻ văn bản và bố cục**: `<h1>` đến `<h6>`, `<p>`, `<ul>`, `<li>`, `<a>`, `<img>`, `<button>`.
- **Biểu mẫu**:
  - Sử dụng `<form>`, `<input>`, `<select>`, `<button>` để tạo form liên hệ.
  - Áp dụng `placeholder`, `required`, `type="email"`...

---

## Kiến thức CSS đã áp dụng

### Căn bản

- Sử dụng file `style.css` để quản lý toàn bộ giao diện.
- Dùng **reset CSS** để làm đồng nhất trình duyệt.
- Chia bố cục bằng `section`, đặt class theo Block-Element-Modifier (BEM) để dễ bảo trì.

### Bố cục nâng cao

- **Flexbox**: Sử dụng `display: flex` để căn giữa nội dung, chia hàng/cột.
- **CSS Grid**: Áp dụng cho bố cục gallery và các khối dịch vụ.
- Responsive design:
  - Dùng `media queries` để hiển thị tốt trên desktop, tablet và mobile.
  - Điều chỉnh font size, padding, cột theo từng kích thước màn hình.

### Thiết kế hiện đại

- **Gradient**: Dùng `linear-gradient()` cho nền nút và header.
- **Hover Effects**: Hiệu ứng khi rê chuột vào nút, hình ảnh.
- **Transition**: Mượt mà khi chuyển trạng thái.
- **Button styling**: Thiết kế nút CTA nổi bật với `border-radius`, `box-shadow`.

### Typography và màu sắc

- Chọn font từ Google Fonts.
- Phối màu chủ đạo giữa cam – trắng – xám.

### Animation với @keyframes
Dự án đã sử dụng @keyframes để tạo các hiệu ứng chuyển động.

### Áp dụng JS tạo menu responsive
Dự án đã kết hợp **CSS + JS** để tạo menu và chức năng đóng mở menu.
